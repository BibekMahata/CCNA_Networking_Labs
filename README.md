# Lab 01 - Small Office LAN

## Objective
Build and configure a basic small office LAN using Cisco Packet Tracer.

## Devices
- 1 Cisco Switch
- 4 PCs
- Ethernet cables

## Configuration
- IP Addressing
- Switch configuration
- Access ports
- Default gateway
- Connectivity testing

## Network
Network: 192.168.1.0/24
Gateway: 192.168.1.1

## Verification
- Ping between PCs
- Check switch configuration
- Verify connectivity
